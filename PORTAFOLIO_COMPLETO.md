## 🚀 Setup Completo

### Paso 1: Clonar todos los proyectos
```bash
cd "C:\Users\Sebastian Beltran\Documents\Portafolio"
```

### Paso 2: Instalar dependencias (una sola vez)
```bash
pip install -r requirements.txt
```

### Paso 3: Ejecutar setup de cada proyecto
```bash
# Proyecto 1 (ya completado)
cd Proyecto-1-Service-Desk
python scripts/03_analysis.py

# Proyecto 2
cd ../Proyecto-2-Banco
python scripts/03_model_training.py

# Y así sucesivamente...
```
